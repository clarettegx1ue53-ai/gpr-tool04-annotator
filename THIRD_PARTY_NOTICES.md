# Third-party notices

The Windows portable application includes Python and third-party components. Their original license and notice files are preserved under `THIRD_PARTY_LICENSES/`; package-relative paths distinguish component and vendored notices.

Versions below are recorded from the installed build dependencies. NumPy, SciPy and Pillow license files include notices for bundled native libraries. The Python notice includes its bundled component notices. Setuptools notices include vendored packages. PyInstaller is the packaging tool; its notice includes the bootloader exception.
