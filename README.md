# GPR Tool04 — 通用图像 / CSV 雷达标注工具

面向探地雷达图像的 Windows 桌面工具，支持灰度图像、通道 CSV、B-Scan / C-Scan 显示及标注导出。

**[下载 Windows 64 位便携版](https://github.com/clarettegx1ue53-ai/gpr-tool04-annotator/releases/latest)**

本仓库分发已构建的便携程序、使用说明和依赖声明，当前未包含 Python 源代码。发布包不包含雷达原始数据、用户图像或标注项目，请使用自己的数据。

## 下载和启动

1. 打开上方下载页，下载 `GPR-Tool04-Windows-x64-2026.10.17.zip`。GitHub 自动提供的 `Source code` 压缩包只有仓库文档，不含程序。
2. **完整解压** ZIP 到有写入权限的文件夹，保留全部目录结构。
3. 双击 `04_打开通用图像CSV标注工具.bat`。也可运行 `portable/Radar_Universal_Labeler/Radar_Universal_Labeler.exe`。

适用 Windows 10 / 11 64 位。便携包自带 Python 运行环境，不需要另装 Python 或 MATLAB。请勿单独移动 EXE、删除 `_internal` 内的文件，或直接在压缩包内启动。首次启动需要少量时间。

## 主要功能

- 导入已有图像或包含多个通道的 CSV 文件夹，指定输入、项目及输出位置。
- 选择 B-Scan / C-Scan 显示；识别采样点数量，并选择保留的采样点范围。
- 自定义横坐标桩号、纵坐标范围及通道信息，显示单个或多个通道。
- 灰度显示、降噪增强及对比，矩形标注、自定义病害类别。
- 多通道同步生成标注；生成的各通道标注相互独立，可单独修改或删除。
- 框选多个标注后批量删除或替换类别。
- 输出带标注图像，支持自定义切片尺寸；跨越切片边界的标注保留各自相交部分。
- 导出时选择纵坐标刻度间隔（米），支持自动或自定义数值。
- 横轴可显示标注列左右边界的桩号短刻线；同列多通道标注存在轻微偏差时取整列外边界。

## B-Scan 与 C-Scan 标注对应

使用同一路段 CSV、相同的桩号范围、行驶方向及通道对应关系，工具按标注的桩号区间和所属通道映射 B-Scan / C-Scan 标注。导出 C-Scan 时，请选择该路段对应的数据并核对通道次序与深度窗。

任意两张无坐标信息的导入图片不能仅凭外观自动建立准确对应。不同图的像素大小可以不同，需以实际桩号、通道和深度设置为准。PNG 是导出时的快照；修改项目内标注后，需要重新导出。

## 纵坐标刻度

在导出设置中选择纵坐标刻度间隔，例如 `0.1 m`、`0.25 m` 或 `0.5 m`。此选项改变刻度显示间隔，纵坐标范围仍按用户设置，标注位置和图像数据范围保持不变。多通道 B-Scan 分别显示每个通道的深度刻度；C-Scan 使用通道编号作为纵坐标时仍显示通道标签。

## 项目与迁移

建议把项目文件和对应输入数据一起保存。迁移到另一台电脑后，如果原输入数据路径已变化，需要重新指定数据位置。保留可编辑项目，不能仅用已烧录标注的 PNG 替代项目文件。
